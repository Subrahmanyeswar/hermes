## 1. Executive Summary & Objective

In Phase 1 Model Migration, the HERMES model layer was upgraded to a modern, reliable, and observable 3-tier architecture. Prior to this phase, HERMES had hardcoded legacy model tags (`qwen2.5-coder:7b`, `mistral:7b-instruct-q4_K_M`, `claude-sonnet-4-6`), forced VRAM deallocation on every inference (`keep_alive=0`), and suffered from immediate pipeline abortion if missing arguments (like `{}`) were generated by the model.

All objectives of Phase 1 have been accomplished:
1. **Locked 3-Tier Model Architecture**: Standardized on DeepSeek-R1 8B (Tier 1), Qwen3 8B (Tier 2), and Stealth Ox-Alpha via OpenRouter (Tier 3).
2. **Normalized Model Provider Abstraction**: Introduced `ModelProvider` base class and `NormalizedModelResponse` dataclass across all providers.
3. **Centralized Configuration**: Centralized all model providers, model tags, timeouts, streaming, and keep-alive parameters in `config/model_config.py`.
4. **Optimized Model Lifecycle (`keep_alive=300s`)**: Eliminated aggressive VRAM purging (`keep_alive=0`) in favor of a 300s warm residency policy, removing massive reloading latency.
5. **Hardened Tool Schema Validation & Recovery Loop**: Implemented proactive parameter schema validation and recovery in Stage 5, preventing crashes from empty dicts (`{}`) by supplying structured feedback back to Tier 1.
6. **OpenRouter Integration**: Integrated OpenRouter chat completions for Tier 3 arbitration with lifetime cost caps ($25.00), SQLite audit logging (`data/tasks.db`), and secure ENV-only credential handling.
7. **Reasoning Tag Extraction**: Added `<think>...</think>` tag extraction in `ResponseParser` to cleanly separate reasoning chain-of-thought from JSON tool calls for DeepSeek-R1.
8. **Preserved High-Resolution Telemetry**: Retained non-invasive latency, token count, tokens/sec, VRAM, and cost tracking across all tiers.

## 2. Before vs. After Architecture

| Architectural Layer | Initial Architecture (Before) | Final Architecture (After Phase 1) |
| :--- | :--- | :--- |
| **Tier 1 Proposer** | Hardcoded `qwen2.5-coder:7b` via Ollama | `deepseek-r1:8b` via `OllamaClient` (`ModelProvider`) |
| **Tier 2 Verifier** | Hardcoded `mistral:7b-instruct-q4_K_M` | `qwen3:8b` via `Tier2Verifier` (`ModelProvider`) |
| **Tier 3 Arbitrator** | Anthropic Claude Sonnet 4.6 direct | `stealth/ox-alpha` via `OpenRouterClient` (`ModelProvider`) |
| **Model Abstraction** | None (Ad-hoc string returns) | Standardized `ModelProvider` + `NormalizedModelResponse` |
| **Configuration** | Scattered across files | Centralized in `config/model_config.py` + `.env` |
| **Ollama Lifecycle** | Forced `keep_alive=0` (Cold reload per call) | Configurable `MODEL_KEEP_ALIVE="300s"` (Warm residency) |
| **Missing Args Handling**| Immediate crash / task abort on `{}` | Schema validation recovery loop with structured feedback |
| **Reasoning Model Support**| None (could break on `<think>` blocks) | `<think>...</think>` extracted to `reasoning` attribute |
| **Cost Tracking** | Anthropic only | OpenRouter SQLite tracking with $25 lifetime cap |

## 4. Configuration & Environment Variables

All settings are configured via `config/model_config.py` and overridden via environment variables:

```bash
# Tier 1 (Proposer / Fast Generation)
TIER1_PROVIDER=ollama
TIER1_MODEL=deepseek-r1:8b

# Tier 2 (Verifier / Cross-Family Quality Audit)
TIER2_PROVIDER=ollama
TIER2_MODEL=qwen3:8b

# Tier 3 (Arbitrator / Escalation)
TIER3_PROVIDER=openrouter
TIER3_MODEL=stealth/ox-alpha
OPENROUTER_API_KEY=<SECRET_LOADED_FROM_ENV>

# Lifecycle & Performance
MODEL_STREAMING=true
MODEL_TIMEOUT_SECONDS=180
MODEL_KEEP_ALIVE=300s
```
